# Frontend preview

ภาพตัวอย่างการออกแบบที่ปรับตามวิดีโออ้างอิง: พื้นขาว ปุ่มแดง แบนเนอร์แดงเข้ม ช่องค้นหาตรงกลาง และการ์ดอนิเมะแนวนอนสองคอลัมน์ พร้อมหน้าจอมือถือและธีมมืด

- `animehub-desktop.png`: หน้าแรกที่ความกว้าง 1440px
- `animehub-mobile.png`: หน้าแรกที่ความกว้าง 390px
- `animehub-login-desktop.png`: หน้าเข้าสู่ระบบที่ความกว้าง 1440px
- `animehub-login-mobile.png`: หน้าเข้าสู่ระบบที่ความกว้าง 390px

ภาพบันทึกจาก React app ใน Chromium โดยตอบ API ทดสอบด้วยข้อมูล 50 เรื่องจาก `backend/data/jikan.json`; ไม่ได้เพิ่มข้อมูลจำลองหรือ fallback ใน production app. การใช้งานกับข้อมูลบัญชี รีวิว และรายการอยากดูจริงต้องเปิด Go backend ที่พอร์ต 8080 ตาม README ของโปรเจกต์

ตรวจสอบแล้ว: React tests 40 ข้อ, production build, การค้นหาและส่งคำค้นจากหน้าแรก, ตัวกรองหลายแนว, เรียงลำดับ, เปิดหน้ารายละเอียด, หน้าเข้าสู่ระบบ, การจดจำธีม และขนาดหน้าจอ 320–1440px. การตรวจผ่านเบราว์เซอร์ครั้งนี้ไม่ได้ทดสอบ Go/PostgreSQL แบบ end-to-end
